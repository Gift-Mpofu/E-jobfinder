# **App Name**: E-Jobfinder Pro

## Core Features:

- CV Upload: Allows the user to upload their CV in PDF or DOCX format.
- Job Description Input: Provides a text area for the user to paste a job description.
- Match Analysis (Prototype): Analyzes the compatibility between the uploaded CV and the job description and determine a match score, list strengths, identify missing keywords, and provide improvement suggestions, and reason if and when some piece of information should be incorporated. NOTE: This is a prototype only, using placeholder data. Future releases may use generative AI.

## Style Guidelines:

- Primary color: Vibrant orange (#FF914D) to convey energy and focus on career advancement.
- Background color: Light, desaturated orange (#FAEBD7) to create a soft and professional backdrop.
- Accent color: Analogous yellow-orange (#FFB347) to highlight key interactive elements and calls to action.
- Body and headline font: 'Inter', a grotesque-style sans-serif, will be used for a modern, neutral, and objective feel.
- Clean and minimal layout with a professional look using Tailwind CSS. Clear sections for CV input, job description, and match results.
- Use simple and professional icons to represent different sections and actions.
- Subtle transitions and animations for a smooth user experience.
